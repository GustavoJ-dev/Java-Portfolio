# 💼 Developer Portfolio

- Portfólio pessoal desenvolvido para apresentar minhas habilidades, projetos e evolução como estudante de Análise e Desenvolvimento de Sistemas com foco em Desenvolvimento Backend Java.

- O projeto foi desenvolvido utilizando tecnologias da Web, priorizando um código organizado, responsividade e uma interface inspirada no ecossistema Java e na IDE IntelliJ IDEA.

** ✨ Funcionalidades
- Página inicial com apresentação profissional.
- Seção Sobre com resumo e principais competências.
- Cards interativos de habilidades.
- Área de projetos com links para o GitHub.
- Seção de contato com acesso rápido às redes profissionais.
- Menu responsivo para dispositivos móveis.
- Layout adaptado para desktops, notebooks, tablets e smartphones.


## 🛠️ Tecnologias Utilizadas
- HTML5
- CSS3
- JavaScript (ES6+)
- Lucide Icons

## 📱 Responsividade

- O projeto foi desenvolvido seguindo a abordagem Desktop First, contando com estilos específicos para:

- 💻 Desktops
- 💼 Notebooks e Tablets
- 📱 Smartphones


## 🎯 Objetivo

- Este portfólio foi criado para reunir meus principais projetos, demonstrar minha evolução como desenvolvedor e servir como vitrine para oportunidades de estágio e desenvolvimento profissional na área de Engenharia de Software e Desenvolvimento Backend Java.
